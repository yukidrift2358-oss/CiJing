# 词境 v0.14：操作引导与小卷练习

本版针对 v0.13 新增规则补充游戏内引导。规则与音景分支沿用原版，引导增加在玩家操作和观察结果之间。

## 随操作出现的提示

“观景”区按关卡呈现当前要学的一件事，淡朱色墨圈指向相关音石、操作或景物。圈线不接收鼠标事件，不能挡住音石与按钮。玩家完成对应动作后，提示保留一小段时间，随后退出或转到下一个相关主题。

- 离岸提示点选或拖动音石入水。
- 荷间水道说明同类短音合成长音，两份材料只占一处。
- 夜雨说明角声落雨，接着提示空拍使水面平静、倒影出现。
- 风骤引导观察羽声造成的帘与花瓣变化。
- 卷帘提示选中长羽后拆分，提出“若只轻揭帘角呢”，不在该条提示中公布整套拍位答案。
- 首次已有线索却未能完成的演奏，提示点拍位回看；回看后提示续听，并说明完整听曲才判定通关。
- 自由谱曲说明异音合声与取音入口。

提示可点“收起”，收起记录和已学记录分别保存。所有主题仍可从“引导”打开；引导不会替玩家移动正式音石、完成主线或开启章节。

## 可重看的小卷练习

“试一试”打开当前主题的小卷，“引导”可以选择八个主题。小卷使用独立 Board，合成、拆分、合声直接复用正式规则，景物复用 SceneScore 演算。原关卡的音石、资源、线索、章节进度不参与练习。

练习由玩家按按钮推进。雨与留白练习会演示一声短角，在玩家留一拍空并等待后，显示消退的水波和倒影。拆风练习先听长风造成的落花，再在同样两份材料的另一小卷中拆成长短对比；两次短风让帘角升起，花瓣保持不落。

小卷是带交互按钮的规则示范，正式关卡中的拖动、点选、X 拆分仍通过对应操作学习；不将按钮示范写成已经验证玩家掌握了全部操作。

练习可随时略过、按 Esc 返回或从引导重开。等待动画期间重复点击无效；退出后停止练习声音，失效的等待不能重新打开窗口、写入主线结果或改动新打开的练习。

## 画面与文字

提示沿用现有书写字体、纸色与朱墨，放在右侧原有留白中。诗句用于景物与叙事，操作提示直接写需要点击的位置与结果。每段只解释当前关系，不把所有新规则塞在首次进入时。

水波与倒影的位置向画面内侧调整，避开底部景物说明，保证练习要求玩家观察的结果确实可见。小卷中的长风、短风共用庭景与纱帘图层，通过相同状态规则产生差别。

## 验证方法与限制

新增 Windows Player 检查覆盖雨声、空拍显影、长短风区别、练习与主线隔离、收起后不重复、重看、退出时取消等待、失败后回看续听与引导记录保存。另保留九关、两种卷帘结果、隐藏曲与音量控制检查。

验证结果以 `v014-验收结果.json` 和实际日志为准。检查通过代表程序行为与上述规则一致，不代表已经进行了新玩家可发现性测试；没有新增真人测试样本或主观满意度结论。
