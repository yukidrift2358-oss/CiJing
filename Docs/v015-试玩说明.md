# 词境 v0.15 试玩说明

解压后运行 CiJing.exe，并保留同目录的数据文件夹。旧版旅程和引导记录可以继续使用。

## 本版从哪里开始看

已有进度的玩家，可从首页“重访旧景”进入第四至第六景，也就是“雨后海棠”。本章三景已改为按实际景物目标通关，拍位可以自行安排。

“旧景余音”提供溪亭水痕和归舟灯两处小型回访；“此行留卷”收录灯芯、纸折、所留之物和回访发现。暂未满足开放条件的旧景会显示为不可选。

## 基本操作

点击行囊音石，再点击水纹空位，也可拖动。两枚同类短音可合成长音；选中长音后按 X 拆分，Z 撤销。空格完整听曲或止音，E 入景，Esc 返回。

点击水纹上方拍位可回看；“续听”从选定拍接着听。分段试听只供观察，通关需要完整演奏。右上方“试一试”和“引导”保留八个可重看的小卷主题。

## 雨后海棠的新目标

夜雨需要三滴能分别听清的短雨，并在曲尾等水面平静。风骤需要两阵长风，前一阵退去再起后一阵，曲尾候落瓣停稳。

卷帘使用两份角音、两份羽音。先在帘前听过雨，再卷起帘幕，等待风歇、水影清楚。长风会落花见笺，两次微风可留一枝残红。两条路线都能续卷。

“隔帘一问”可以留下一次猜想，也可暂不作答。帘起之前，花枝层不可见；演奏达成目标后，点“观花”比照所想与所见，再将所见入卷。亲见之后，旧猜保持原样。改动已奏过的音石后，需要重新完整演奏。

## 物件和旧景

主画面左侧的归舟灯可以点读；卷帘后出现的书笺也可展看。灯芯与纸折都有近景细节，记录会影响“此行留卷”中可读的内容，回信随物也对应卷帘结果。

回访小卷仍用点选、放置和八拍演奏。上方为水纹，下方两枚是独立行囊；回访不会改变主线材料。需要重试可点“重置小卷”，也可随时返回。

## 声音与保存

音石点击即时回应，正式演奏按八拍播放。帘后的声音较柔闷，帘起后更清楚，隔水有轻微延迟回应；完成时会接出收束乐句。音石与配乐可在“乐声”中分别调节。

正式存档仍为本机 journey-v1.json。自动检查使用独立 test-save.json。设计说明、素材来源、程序检查结果及空白试玩观察表附在包内；没有预填真人测试结果。
