# v0.4：随解谜成画

替换 v0.3 的精致立绘与眨眼演出。人物和环境共同绘制在画卷里，使用统一的简化笔触，保留文字剧情。

九景解谜推动疏墨初稿、黑白线稿和低饱和设色。过关先停留 1.45 秒显示晕染，再进入剧情。“观画”查看已获得的画卷。

InkGrowth 材质使用三阶段图像、多尺度噪声边缘、局部湿墨脉冲表现渗染。声音触发轻微墨迹扰动；剧情页可关闭持续扰动。没有使用 Live2D Cubism，也不宣称实际逐笔绘制。

终稿降低饱和度与对比度，保留纸色。研究了《狐行者》官方 Steam 截图的手绘轮廓与层次，没有使用其角色或纹理。研究图片只用于本地分析，不随发布包分发。
https://store.steampowered.com/app/4767160/Fox_Wanderer/

美术提示词见 AI-Painting-v04.md。初稿与线稿以终稿为编辑参考；过渡采用墨染显现，主要物件的位置尽量保持一致。

验证：三阶段实际程序截图、墨染过渡前后的数值与画面、九关回归、剧情衔接、存档回读。以本轮 Validation 日志为准。未做真人体验或多设备测试。
