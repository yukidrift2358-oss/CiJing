# v0.10 合声与藏曲

音乐：保留现有三章采样编排，提高配乐混音权重。演奏时配乐保留到设定音量的 48%（原为 16%），音石触发有间隔限制的笛声回应；长音回应稍强。异音合声采用双音分层，第二音延后 0.11 秒进入。没有新增网络音频，沿用已附授权的竖琴与长笛采样。尚未进行真人耳机与音箱听感测试。

二合：原同音短音合成长音；另新增异音配对：宫角、商羽、角徵。选短音，点“合声”，再选另一短音。合声占一格、计两份材料，不能继续叠合，可拆回原两音，支持撤销与存档。主线仍须依景用单音，合声用于自由谱曲和藏曲挑战。

三则可选藏曲：自由谱曲中，依次放配方合声、配方低音短答：疏雨为第一、五拍，雁回为第二、七拍，落花为第三、五拍；其余六拍留白；试听后永久收录对应题句。不同配方具有不同双音与回应音。行囊材料有限，拆分和撤销可用于改谱。菜单“拾遗”和游戏“藏曲”可查看配方、条件与已收录题句。隐藏题句均为本作自撰，不冒用李清照名义。

新数据 echo 保存合声第二音，secrets 保存三句解锁位；旧存档缺省为零，无需重置正常进度。验证使用独立测试存档。最终构建、九关与合声挑战回归结果见本版 Validation。
