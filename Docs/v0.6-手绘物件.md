# v0.6：手绘交互物件

九件探索道具改用独立的透明底 AI 手绘 PNG：船桨、水痕石、归舟灯、雨钵、折枝、落花书笺、西楼灯、溪流书笺、对岸回信。

删除旧 QuestPropGraphic 几何线条图形。物件放大显示，保持原图比例，使用淡彩、细墨轮廓和柔和材质细节；灯笼、木桨、陶钵、枝叶、书信具有不同轮廓，不再复用同一线框。

物件图与下方名称牌都可点击，悬停时轻微放大和暖色高亮，已收集状态实时更新。保留纸底文字，避免与背景混淆。

原始图与完整提示词见 Assets/Resources/Props 与 Docs/AI-Props-v06.md。游戏中使用 PNG 的透明通道，没有使用 JPG 的不透明矩形背景。素材均由内置 image_gen 生成，未使用网络库存物件。
