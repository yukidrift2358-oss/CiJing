# 资源来源与文化依据

## 当前界面字体

马善政楷书 Ma Shan Zheng，SIL Open Font License。
来源：https://github.com/google/fonts/tree/main/ofl/mashanzheng
原始字体：https://raw.githubusercontent.com/google/fonts/main/ofl/mashanzheng/MaShanZheng-Regular.ttf
项目文件：Assets/Resources/Fonts/Poetry.ttf。许可全文：Font-Poetry-OFL.txt。

开发时另下载了站酷小薇体，因“回”字字形在本环境异常，已不用于界面。其开发副本 WenKai.ttf 和 Font-OFL.txt 保留来源记录：https://github.com/google/fonts/tree/main/ofl/zcoolxiaowei

## 美术

三张背景均由本任务使用内置 image_gen 生成。提示词见 AI-Art-Prompts.md，项目消费副本位于 Assets/Resources/Art。建筑与空间构图为艺术创作，未经历史形制专项考证。

## 声音与界面

五音短音及长音由原创谐波合成代码实时生成。未使用参考视频中的录音、曲谱、动效或其他商业游戏素材。程序界面、水波、小舟、雨线、落瓣和月光为本项目绘制。
