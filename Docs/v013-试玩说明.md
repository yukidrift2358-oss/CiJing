# 词境 v0.13 试玩说明

Windows 试玩包解压后运行 `CiJing.exe`，请保留同目录的数据文件夹。窗口可调整大小。

## 入卷与操作

“入卷”继续本机进度，“重访旧景”选择已解锁的景，“自在谱曲”进入自由编排。

点击或拖动音石，将行囊里的声音放入八拍水纹。两枚同类短音可合成长音；选中长音后按 X 拆开，按 Z 撤销。空格完整听曲或止音，E 打开探索卷轴，Esc 返回。

探索卷轴可拖动，也可用 A、D 移动。鼠标靠近水墨物品时出现题签，点击读线索；每景读到一处即可开始试音，其余线索可选读。

## 声音怎样影响画面

宫声行舟，角声落雨，羽声起风，徵声惊起水鸟。长声作用持续得更久，长风会吹落花瓣；短风能轻揭帘角。留白让雨声、水波与飘动的纸笺渐渐安定。西楼的两拍停歇还可能带来隔水回音。

点击水纹上方的一至八拍，可回看该拍结束时的景；“前拍”往回一拍，“续听”从选定拍重新听起。分段试听不会判定通关，完成目标后请用“听曲”完整演奏。画中出现新迹时，可打开“画记”读题句。

## 卷帘的可选路线

第二章第三景，两滴短角相隔半圈。长羽放在中点，可卷帘落花，显出旧书；将长羽拆为两枚短羽，分置两个中点，则可卷帘留花。两条路线均能续卷，章末文字和后续回信有所不同。

## 自在谱曲

同音合成长声；选中短音、点“合声”，可将宫角、商羽或角徵相和。合声触发两种景物效果，也能拆开。顶栏“取音”可向行囊空位添短音，主线仍使用每景固定的材料。

“保存短曲”同时保存曲目、场景结果和所属章节；重新进入自由谱曲时会重建该曲末拍的景象。“藏曲”内保留三首隐藏曲的题句与摆法。

## 音乐与存档

“乐声”分别调节音石和配乐，风雨环境声跟随配乐音量。配乐包含真实竖琴、长笛录音的原创编排，音石演奏时自动降低伴奏。

正式游玩沿用本机 `journey-v1.json`；自动检查使用单独的 `test-save.json`，不会替玩家完成正式旅程。旧版试玩包与视频均保留；本版内容变化详见制作记录。

## Unity 工程

使用 Unity 2022.3.62f3c1 打开工程根目录，入口场景为 `Assets/Scenes/CiJing.unity`。已附完整 Assets、Packages、ProjectSettings 和设计文档。资源已生成，正常运行和构建不需要重新运行音频处理脚本。

编辑器构建入口为 `CiJing.EditorTools.BuildGame.Run`。该入口会重新创建入口场景，手工场景修改应同步到构建逻辑或改用常规 Build Settings 构建。
