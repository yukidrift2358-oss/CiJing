# 词境 v0.15 · 视频 v3 制作记录

本轮将原 v2（对应 v0.12）更新为 v0.15 展示。旧片和旧工程包保留，新成片使用 v3 文件名。

主要证据是已构建的 v0.15 Windows Player。原生录制入口按实际按钮与音石操作运行，记录三章九景及三则藏曲，输出 1280×720、15 fps 原始画面、音石事件 CSV 和阶段标记。录制日志包含 `CIJING_FILM_PASS 9 levels and 3 secret songs`。成片以 1920×1080、30 fps 封装；重复帧不代表原生游戏运行性能测量。

九景主线保留从入景、寻物、布置音石、演奏到结果的流程。藏曲演示预置配方材料，画面注明。回访、留花路线、灯芯、引导和留卷使用本版运行检查保存的真实截图，注明“运行截图 · 定格阅读”，没有把截图包装成连续操作。历史对照使用 v0.3、v0.6、v0.13 的保留截图，各自标明版本。规则图为本轮绘制的说明，不充当历史画面。

音频由项目自己的 score、ornament、harp、flute、风雨纹理和 coda 样本制作，按录制帧号重建音石起音，再加入讲解旁白与剪辑混音。CSV 没有记录完整实时混音参数，所以成片不是 Unity 声场、滤波、声像和环境衰减的精确录音，不能用成片测量游戏音效延迟或判断完整混音实现。游戏内声音实现以 MusicBed 与实际 Player 为准。

旁白使用 `zh-CN-YunxiNeural`，语速 -3%，讲解稿改为按条件、操作、结果与限制组织。五音中的角、徵在语音输入中作读音处理，字幕仍保留正确汉字。字幕依据语音边界拆分，逐段核对文本与脚本，并检查结尾没有超出画面。配乐在讲解下方退后，演奏片段保留可听的音石。

录制使用临时演示存档；完成后恢复原 journey-v1.json 与 test-save.json。用户日常进度不作为公开素材上传，备份也不进入资料包。
