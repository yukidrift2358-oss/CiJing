# 继续修改视频

成片独立提供。视频制作资料包保留文案、逐段配音、字幕时间、SVG/PNG 图示、运行截图和合成脚本；原始录制包保留实际画面、音石事件和阶段标记。两个包都以 `CiJing-Video-v3` 为根目录，解压到同一个 Deliverables 目录即可合并。

建议目录：工作目录下放 CiJing 工程与 Deliverables；后者内放 CiJing-Video-v3。音频样本从工程 `Assets/Resources/Audio` 读取，画面、文案和截图从视频目录读取。依赖见 edit/requirements.txt；Windows 绘图需已安装微软雅黑。FFmpeg 可由 imageio-ffmpeg 提供，也可设置 FFMPEG_PATH。

`edit/script.json` 是讲解正文、片段顺序和画面来源。修改后运行 neural_voice.py，正文未变的配音会保留，变动的段落重新生成语音和时间边界。其后运行 render_v3.py 更新影片、字幕和章节，再运行 validate_media.py 检查。设置 CIJING_RENDER_IDS 为逗号分隔的片段 ID，可只重做对应片段，再重新拼接成片；此操作需要保留其余已输出的 edit/segments 和 rendered.json。

`diagrams/*.svg` 可直接编辑；修改图后须同步输出 PNG，再重做使用该图的片段。也可运行 edit/diagrams_v3.py 重新生成图示。

初次拿到资料包而没有缓存片段时，应完整运行 render_v3.py。脚本以本轮现有录制事件重建音乐，不是实时录音工具。新增内容若改用实际操作录像，仍需保留字幕标记、更新讲解内容，并修改制作记录的证据说明。

原始录制依赖及 Unity 许可证不随资料包提供。无需重新构建游戏，即可使用已有视频素材继续剪辑。个人存档备份与未验证录制实验没有打包。
