# v0.7：水墨物件与悬停提示

九种探索物件改用新生成的黑白墨稿，减少彩色、发光、精细装饰和写实材质。以断笔、飞白和灰墨保留辨识轮廓。物件缩小，保持原图比例；运行时使用统一墨色材质，浅色表面融入画卷，避免白底方块。

平时只显示水墨景物，隐藏名称牌和收集标记。鼠标移入物件区域后，题签淡入，显示名称以及“点击查看”或“已收入词笺 · 点击重看”；墨色略深，不再放大或暖色发光。移出后题签收起。题签始终有纸底，以保持字与背景的区分。

物件图可直接点击，悬停题签也可点击。拖动卷轴或使用 A、D / 方向键移动后，继续在景物中寻找；已收集的诗句仍留在线索册中。九关规则、二合、音乐和存档格式沿用上一版。
