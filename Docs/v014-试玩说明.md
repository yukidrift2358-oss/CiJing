# 词境 v0.14 试玩说明

解压后运行 CiJing.exe，保留同目录的数据文件夹。旧版正式进度可以继续。

基本操作沿用 v0.13：点选或拖动音石入水，同类短音相合成长音；X 拆分，Z 撤销，空格听曲或止音，E 入景寻迹，Esc 返回。入景读到一处线索即可试音。

## 本版新增的引导入口

游玩右上方“观景”区会出现本景相关提示，淡朱色圈线标出可操作的位置。按提示完成动作后会显示结果说明。点“收起”后，该主题不再自动出现。

“试一试”可进入当前主题的小卷练习；“引导”可随时选择落音、合成、雨声、留白、风声、拆风、回看和自由合声八个主题，已试过的主题也可以重看。

练习独立使用材料，不改变当前关卡布局或主线进度。点朱色按钮逐步推进，等雨声、水波或帘角变化后，再做下一步。点“略过练习”“返回此景”或按 Esc 都可退出。

## 回看与继续演奏

第一次未能完成目标时，游戏会提示回看。点击水纹上方一至八拍，显示该拍结束时的景；“续听”从选定拍重新播放。分段试听用于比较局部变化，通关仍需点“听曲”完整演奏。

原有两种卷帘解法、画记、取音、藏曲、曲景共同保存与分层配乐均保留。详细规则见 v013-试玩说明.md，本版引导说明见 v014-操作引导与小卷练习.md。
