# v0.8：纸面、按钮与音石界面

菜单、页眉、提示与对话底板统一使用细纸纹和柔化边缘。保持浅纸色与深墨字的对比，不让正文直接压在复杂山水上。

主操作采用低饱和朱砂笔触底和浅纸色文字；次要操作以淡墨下划线与轻墨色洗染表示。悬停时文字与墨色变化，按下时笔触加深，不可用时淡化并拒绝点击。装饰层不接收射线，点击区域保留完整按钮大小。

原来的方形音石格改为不规则墨圈，空位使用疏淡断线。已有音石保留五音、长短文字与淡彩区分；选中和播放中的位置使用朱砂圈表示。节拍序号的底形也改为圆形水纹。

按钮和底部说明增加快捷键标记。空格：听曲 / 止音；Z：撤销；X：拆分所选长音；E：入景；Esc：返回。快捷键小字使用本机微软雅黑，以保证英文字母清楚；按钮正文沿用书法字体。弹窗打开或关卡演出期间仍按现有交互限制处理。

水墨物品和悬停题签沿用 v0.7，并同步使用本版按钮样式。音量控制的拖柄改为小墨滴。

主要改动：GameApp.cs、GameApp.Exploration.cs、新增 InkUI.cs 与 Resources/PaperUI.shader。未新增网络素材或图片生成素材。

检查范围：Unity 构建、70 项规则断言、实际 Windows Player 九关流程、音石点击与拖动、物件悬停和题签点击，以及按钮的悬停、按下、移出与禁用状态。快捷键检查调用与键盘相同的操作入口，未模拟物理键盘输入。视觉检查使用本版运行截图，不计作真人用户测试。最终结果以 Validation 中的日志为准。
