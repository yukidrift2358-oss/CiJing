# v0.13 新增绘图素材

工具：会话内置 image generation。两张图片均为新生成的透明 PNG；没有覆盖旧版背景或道具。

## garden.png

用途：雨后海棠的独立庭景层，低饱和水墨设色、右侧海棠、下部窗沿、大面积留白。画面不含角色与文字。

生成要求：Song dynasty poetry puzzle game environment overlay; sparse ink outline windowsill, graceful begonia branch entering from right, dusty rose flowers and celadon leaves, misty lake and tiny remote bridge; central negative space, restrained ivory wash, feathered transparent edges; no curtain, UI, text or saturated colours.

原文件：exec-fbdd47da-ac58-4f91-83d7-258c39541feb.png。

## curtain.png

用途：独立纱帘图层，运行中依据音景状态收卷、轻摇。

生成要求：single hanging silk bamboo gauze curtain, transparent background, pale celadon-gray silk, fine ink outlines, diluted watercolor edges, narrow tassel, asymmetric folds, loosely curling lower edge; no scenery, frame, text or ornate architecture.

原文件：exec-560edabc-a435-4bd8-bbe1-f1478f2b4e84.png。

运行时的雨线、水波、落瓣、倒影与舟身运动由工程绘制，不宣称为 Live2D 模型动画。
