# v0.3 使用补充

打开 CiJing.exe 即可游玩。三章九景，后六景改为关系推理。

剧情：入章及章末播放持笺人的词意引导。Enter 或“继续”可先显示整句，再翻页；“略过此段”直接结束当前演出。“静态立绘”可关闭动作。关卡顶部“听旧事”可重播本章引导。

解谜：观察按钮先补充不同线索，再显示一个可行例子。夜雨、风骤、卷帘等关卡允许整体移动节奏，只要相对关系仍然成立。试听后出现的文字提示指出当前仍需检查的关系。

旧存档：已解锁章节与自由谱曲保留；旧版当前关卡的音石会重置为新版材料。

立绘为 AI 生成的虚构持笺人，通过 Unity 分层动效、眼部帧与逐字文本演出；不是已经绑定的 Live2D Cubism 模型。
