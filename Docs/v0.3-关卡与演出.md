# v0.3：关卡推理与动态演出

## 后六关

夜雨：三次短角形成环形节奏，三个停顿分别为 2、2、1 拍，可旋转布局。
风骤：两声长羽相隔四拍，可选择不同起点。
卷帘：两滴短角相对，长羽位于两者中点；两种方向及不同起点均可。
月上西楼：奇数拍的四声商角构成倒序回答，两种顺序均可。
锦书未至：长宫在前三拍起，第一短羽晚两拍、第二短羽再晚三拍，有三个有效起点。
两处闲愁：前半句宫长商短，后半句提高一级为商长角短；材料分配与留白同时满足。

“长音”仍是一个位置触发的长衰减音色，不会占用第二格。邻格留白要求属于解谜条件，不是音轨锁格。各规则均在 VerseRules 中独立判定。

关卡中不再用长痕短印泄露目标位置。观察按钮逐步展开关系证据，随后提供一个可行例子。试听不成功时给出当前关系检查提示。

## 剧情与动态立绘

三章各有入章及章末演出，新增“听旧事”入口可重播入章演出。
虚构角色“持笺人”只负责引导词意，不充当李清照真实肖像，不把新增对白当作史料。

已实现头身分层、呼吸、轻微摆动、指针视差、眼部局部眨眼帧、逐字文本、继续、略过与静态立绘开关。Enter 可推进文字。

技术实现为 Unity uGUI 分层 2D 动效；没有导入 Live2D Cubism SDK、.moc3 或参数化网格绑定，不应称为已完成 Cubism 模型。角色美术与闭眼帧由内置 image_gen 生成，提示词见 AI-Portrait-v03.md。

## 存档迁移

保留原存档位置和已解锁关卡；旧规则版本棋盘会重置为新关卡初始材料，自由谱曲保留。rulesRevision=3。

规则检查新增关系约束反例与多解正例。九关自动运行验证仍通过正常 EventSystem 点击路径完成，并覆盖入章剧情翻页、略过、动态立绘截图与闭眼帧、章末剧情转诗词页。以 Validation 中本轮日志为准。尚未进行真人难度、听感或多设备测试。
