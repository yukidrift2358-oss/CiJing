# v0.5：卷轴探索、线索与采样配乐

本轮针对三项反馈：文字和背景混在一起、目标与提示不足、合成音色缺乏乐器质感。

1. 主菜单、关卡标题、导语、线索、底部操作区与剧情对白提供稳定纸底。选中音石保持浅底深字。卷轴道具的查看入口同样使用纸底。
2. 新增横向卷轴，拖动画面或 A/D、左右键、向左/向右按钮移动。每景三个可点击道具，展示相关诗句和关系线索，触发音石试听；线索写入本地存档，可打开线索册重看。九景合计 27 次道具观察，不再依靠单一提示按钮反复翻字。
3. 收齐三处线索后才能完成当前谜题。仍可提前试音和编排。探索是拖动画卷与道具调查，没有加入平台跳跃或自由角色移动。
4. 主线增加没有落款的信、散落归路、庭中失去踪影的收信人和对岸回声，引导玩家寻找散落词句并恢复归途画卷。该剧情是原创改编。
5. 五音使用 VSCO 2 CE 竖琴录音重采样，区分短/长余韵；三章各有 44.8 秒原创采样配乐，含竖琴分解、低音与长笛乐句。音石演奏时自动降低配乐，两个音量分别调节。不是古琴或古筝录音。

来源与许可见 Audio-Credits-v05.md、VSCO-LICENSE.txt 和 VSCO-Readme.txt。

验证范围：九关、27 处道具可达性、线索与进度保存回读、探索返回音石、音乐资源加载和播放、数值音频峰值分析、实际画面检查。自动运行不等同于真人趣味和听感评价。
